# Mini Project Management Software

**Team 14** | Software Engineering Mini-Project

A mini project management software where users can define projects, create tasks, allocate them to team members and track progress.

## Key features (from the SRS)

- Registration, login and role-based access (Admin, Project Manager, Team Member)
- Create, edit and archive projects; manage project members
- Create, edit, delete and comment on tasks
- Assign and reassign tasks; "My Tasks" list
- Update task status and view a progress dashboard
- Overdue highlighting, filter/search and CSV progress report
- Admin user management and activity log

## Repository contents

- `docs/` - SRS and other project documents
- Project board: see the **Projects** tab (backlog, story points, Sprint 1 and Sprint 2)

## Workflow

- `main` is protected: all changes go through a pull request raised by the assigned team member and reviewed by the repo owner.
- Each backlog item is a GitHub issue titled `[BL-xx]` with its source requirement and acceptance criteria.
